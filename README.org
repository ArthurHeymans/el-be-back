Ebb is a +terminator+ terminal emulator for Emacs, written in pure Elisp.  It
keeps Eat's user-facing model while separating terminal state from buffer
rendering.

This README is kept short to avoid the earmarks of being a pure slop project, even
though its entirety is AI generated.

Open a terminal with:

#+begin_src text
M-x ebb
#+end_src

See [[file:docs/ebb-deepdive.org][the architecture deep dive]] for how Ebb works and why its rendering differs
from Eat.  [[file:docs/ebb-comparison.org][The comparison table]] covers Ebb, Eat, and Ghostel.  The benchmark is in
[[file:bench/ebb-bench.el][bench/ebb-bench.el]] and requires native compilation for an accurate Elisp
comparison.

* Requirements

- Emacs 29.1 or newer

* Installation

Ebb is not on a package archive yet.  Install it from this repository with
=package-vc= (Emacs 29+).  The package is named =ebb=, which differs from the
repository name, so the name must be given explicitly -- a bare URL install
guesses the wrong package name and fails.

With =use-package= (Emacs 30+):

#+begin_src elisp
(use-package ebb
  :vc (:url "https://github.com/ArthurHeymans/el-be-back" :rev :newest))
#+end_src

Or with plain =package-vc=:

#+begin_src elisp
(package-vc-install '(ebb :url "https://github.com/ArthurHeymans/el-be-back"))
#+end_src
